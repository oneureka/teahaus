name: code-review
description: Review code changes for quality and consistency
---

## Correctness

- Logic errors and unhandled edge cases
- Async operations without error handling
- Missing null or undefined guard on access

## Clarity

- Dead code and unused imports
- Overly long functions or components
- Duplicate logic that could be extracted

## Style

- Inconsistent naming
- Misplaced files or imports
- Missing or insufficient type annotations
